# Historical note: Ubuntu widget 0.3

Version 0.3 introduced packaged HTML, native messaging and authenticated read-only Ubuntu resource measurements. HTML/CSS/assets are supplied by the Windows provider, without a local HTML server or a dependency on a running dashboard for rendering.

This note is historical. Both widgets now have their own packaged web content. Use the [current widget guide](README.md), [architecture](DEVSTACK-0.4.md) and [release notes](CHANGELOG.md) for installation, security boundaries and measurement scope. Do not install an old bundle based on this filename.
