# Historical note: Ubuntu widget 0.3.5

This version restored the transparent dark outer surface from 0.3.3. The internal cards, typography and light theme were preserved. Short native loading indicators and transient host backgrounds remained unchanged.

The current package retains that appearance and adds later interaction fixes. See [widget guide](README.md), [technical reference](DEVSTACK-0.4.md) and [release notes](CHANGELOG.md).
