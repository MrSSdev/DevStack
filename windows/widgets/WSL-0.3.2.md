# Historical note: Ubuntu widget 0.3.2

The native bridge was aligned with the one-argument WebView2 `postMessage` contract. Startup retries and diagnostics distinguish unavailable messaging from successful read-only resource delivery. Displaying resource data alone never grants command authorization.

Current behavior and setup: [widget guide](README.md), [technical reference](DEVSTACK-0.4.md), [release notes](CHANGELOG.md). No separate action is required for an already configured current installation.
